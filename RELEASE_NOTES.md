# Dashboard refresh — November 2026

A focused polish pass on the main dashboard: clearer layout, smarter submit/pending flow, live stream context, and a cleaner XP experience.

---

## Live & VODs on the dashboard

- When **mikegtcoff** is live, the stream appears in the main column (under Submissions).
- When offline, **Feedback Session** VODs show instead — with calm placeholders if none are available.
- One panel switches Live ↔ VODs; hide for the session if you want it out of the way.

## Welcome card, simplified

- Stronger welcome header (avatar, greeting, subtitle) with room to breathe.
- **Submit Demo** and **Carryover** stay clear and usable — not oversized, not cramped.
- XP lives in one panel: Stored / Used, a battery-style charge bar, and **Use XP** in the same window.
- Legal links sit quietly at the bottom of the page.

## Sidebar that reads like a dashboard

- **TOTM** stays as the familiar button (plus its panel when relevant).
- **Queue** is taller and easier to scan; empty state mimics real queue rows so the layout stays consistent.
- **Status & alerts** is its own window — just the main message (e.g. wait / reviewed), not a wall of indicators.
- **How XP works** + **XP log** sit in a separate tools window; the log stays collapsible.

## Pending & Results that follow the rules

- Empty Pending no longer always says “submit your first demo.”
- If you’ve already submitted and the session rules say you can’t send another yet, Pending hides and **Results** takes over.
- Friendly Mike-voiced wait copy (thank you + short “see you again” + clear timer), without noisy chrome.
- New eligibility check mirrors the real submit rules (open/closed, carryover cooldown, per-session limits).

## XP guide & full log

- **How XP works** opens as a wider, sectioned guide — XP types as cards, community notes and rules side by side — not a tiny text dump.
- Compact XP log shows recent events in a clean list.
- Long history? **View full XP log** opens `/xp/log` with filters for gains / spends, source, and search.

## Languages

- New strings covered in **English**, **Ukrainian**, and **German**.

---

Ship it, enjoy the quieter dashboard, and thanks for sending demos.
